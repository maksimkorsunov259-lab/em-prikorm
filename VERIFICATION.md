# Проверка версии 1.0.0

Проверено в облачной среде 19 октября 2026 года. Использованы искусственные записи и временные профили браузера; реальные данные пациентов в проект не включены.

- 9 проверок модели: чистое начало, отдельность копий, схема и идентификаторы, даты, принадлежность симптомов пациенту, известные продукты, неопределённый состав, отклонение небезопасных фото/объектов, целостность 181 позиции каталога.
- Chromium: сохранение после перезапуска; разделение двух пациентов; фото; чек-лист готовности; план врача; вопросы врачу; добавление и замена данных из копии; отклонение чужого файла; отчёт HTML и печать PDF; удаление еды с сохранением наблюдений; экранирование пользовательского текста; срочная помощь до проверки даты формы.
- 21 экран на четырёх ширинах (320, 390, 768 и 1440 пикселей): нет горизонтального переполнения, авторский блок присутствует, внутренние ссылки ведут к существующим экранам.
- Офлайн-перезапуск: дневники и 181 иллюстрация доступны. Chromium не сообщает ошибок устанавливаемости PWA; manifest ID и область service worker относятся только к ЕмПрикорм.
- Отказ чтения IndexedDB не создаёт пустую замену; неподдерживаемый сохранённый снимок экспортируется без изменений; конфликт вкладок не затирает данные; ошибка квоты останавливает редактирование и позволяет скачать текущую копию; позднее завершение загрузки фото не переносит его другому пациенту; кеши соседних приложений сохранены.
- Оригинальные PNG и встроенные в SVG байты совпадают. Фото автора и QR-код совпадают с ЕмЯйцо. SHA256 иконки: `8e34868b7376bba3b2e2d8e62334b1d6f1008411d8e47466caa1d62a10fa765d`.
- Визуально просмотрены главная страница и каталог на ширине 390 пикселей. HTML-отчёт включает фото только по отдельной отметке.

Физические устройства Android/iOS не тестировались. Медицинские тексты соответствуют авторской редакции правил; перечисленные технические проверки не являются клинической валидацией. GitHub Actions добавлен, но его запуск на GitHub пока не проверен. Публикация репозитория и сайта ещё не подтверждена: удалённый em-prikorm не найден или недоступен, GitHub API отклоняется сетевым прокси с 403.
